# Avaliação do Curso Técnico em Desenvolvimento Web

Aplicação React para gerenciar os registros de alunos do curso técnico em Desenvolvimento Web. O objetivo é facilitar a organização das notas das atividades (compostas por múltiplas entregas) e das avaliações comportamentais.

## Recursos principais

- Cadastro, filtro e remoção de estudantes da turma.
- Registro de três notas acadêmicas formadas pela média de diversas atividades (adicionadas dinamicamente).
- Registro de três indicadores comportamentais para cada estudante.
- Cálculo automático da média final considerando todas as notas preenchidas.

## Tecnologias

- [React 18](https://react.dev/)
- [Vite](https://vitejs.dev/)

## Como executar

```bash
npm install
npm run dev
```

Abra o navegador no endereço informado pelo Vite (geralmente `http://localhost:5173`).

## Scripts disponíveis

- `npm run dev`: inicia o servidor de desenvolvimento.
- `npm run build`: gera a versão otimizada para produção.
- `npm run preview`: executa a pré-visualização da build.
