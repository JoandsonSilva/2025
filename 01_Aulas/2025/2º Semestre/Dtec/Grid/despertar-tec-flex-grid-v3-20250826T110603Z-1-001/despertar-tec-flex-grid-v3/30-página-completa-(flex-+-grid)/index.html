Exercício 30 — Página completa (Flex + Grid)

Enunciado

Header (nav), hero, grid de cards, destaque e footer — tudo responsivo.

Objetivos

  • Combinar Flex (navbar), Grid (cards), `clamp()` (hero) e media queries.

Faça no CSS

  • Navbar em Flex (alinhamento e espaçamento).
  • Hero centralizado com `clamp` no título.
  • Cards: grade fluida com `repeat(auto-fit, minmax(220px, 1fr))`.
  • Destaque e rodapé com espaçamento adequado.
