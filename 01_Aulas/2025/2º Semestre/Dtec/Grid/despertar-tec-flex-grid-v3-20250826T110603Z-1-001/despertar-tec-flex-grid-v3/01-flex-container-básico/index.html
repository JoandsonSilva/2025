Exercício 01 — Flex container básico

Enunciado

Transforme `.container` em um flex container linha. Distribua 3 caixas lado a lado.

Objetivos

  • Ativar `display: flex` no container.
  • Criar espaçamento uniforme entre as caixas com `gap`.

Faça no CSS

  • Tornar `.container` um flex container em linha.
  • Adicionar `gap` entre as caixas.

Dica

Use `display:flex` e `gap: 12px` em `.container`.
