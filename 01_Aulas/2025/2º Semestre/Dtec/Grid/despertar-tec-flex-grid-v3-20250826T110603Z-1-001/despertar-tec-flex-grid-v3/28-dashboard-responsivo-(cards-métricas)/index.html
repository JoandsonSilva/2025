Exercício 28 — Dashboard responsivo (cards métricas)

Enunciado

Cards de métricas em grade fluida; gráficos representados por caixas.

Objetivos

  • `repeat(auto-fit, minmax(220px, 1fr))`.
  • Espaçamento consistente.

Faça no CSS

  • Grid fluida com `auto-fit + minmax`.
  • Cards com borda e padding.
  • Caixa de gráfico centralizada e com altura fixa.

Dica

Modelo de referência: `grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));`.
