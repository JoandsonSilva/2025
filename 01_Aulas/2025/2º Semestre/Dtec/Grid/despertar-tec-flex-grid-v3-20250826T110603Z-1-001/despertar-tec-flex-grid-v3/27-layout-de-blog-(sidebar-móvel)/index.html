Exercício 27 — Layout de blog (sidebar móvel)

Enunciado

Em desktop: conteúdo + sidebar ao lado; em mobile: sidebar abaixo.

Objetivos

  • Áreas nomeadas com media query para reorganizar.

Faça no CSS

  • `blog-layout` com áreas `'conteudo' 'sidebar'` (mobile).
  • Em >=900px: `conteudo sidebar` (2fr / 1fr).
