Exercício 24 — Tabela responsiva (stack)

Enunciado

Empilhe a tabela no mobile sem alterar o HTML: cada linha vira “cartão”.

Objetivos

  • Esconder `thead` no mobile.
  • Usar `td::before` com `content: attr(data-label)`.

Faça no CSS

  • Estilizar tabela normal no desktop.
  • Em ≤700px: esconder `thead`, `display:block` em elementos e usar rótulos com `::before`.
